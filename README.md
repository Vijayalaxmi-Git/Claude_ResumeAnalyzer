# 📄 Resume Analyzer

An AI-powered Resume Analyzer for Recruiters built with
Python, Streamlit and Claude API by Anthropic.

## Features

- Upload PDF / Word resumes or paste text
- Batch analyze multiple resumes at once
- Match resumes against a job description
- Get scores, red flags, matched/missing skills
- Shortlist / Maybe / Reject verdict
- Save all results to CSV
- Filter, sort, add notes, export to Excel

## Tech Stack

- Python
- Streamlit
- Claude API (Anthropic)
- Pandas
- pdfplumber
- python-docx

## Setup

1. Clone the repo
2. Create a virtual environment
3. Install dependencies: `pip install -r requirements.txt`
4. Create `.env` file: `ANTHROPIC_API_KEY=your_key_here`
5. Run: `streamlit run app.py`
